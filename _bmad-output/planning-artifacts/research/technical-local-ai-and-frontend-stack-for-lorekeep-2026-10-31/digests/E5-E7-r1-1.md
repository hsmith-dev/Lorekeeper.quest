### Tentative recommendation
- **Recommend:** Sigma.js 4.0.4 with graphology and @react-sigma/core 6.0.0. All are MIT, React 18 is an official peer, and sigma alone is about 94 KB gz. WebGL rendering (still to be confirmed) should handle 500 to 5,000 nodes. Louvain clustering and ForceAtlas2 are available through graphology packages (still to be confirmed); ForceAtlas2 can run in a web worker, so the CPU cost lands on the client.
- **Runner-up:** react-force-graph-2d 1.29.2. MIT, about 58 KB gz, the simplest API, and peer `react: *`. Canvas plus d3-force should cope with about 500 nodes and 1,500 edges.
- **Not chosen:** Cytoscape (MIT, about 134 KB gz before layouts) has the richest set of layouts but is heavier. React Flow (MIT, about 59 KB gz) is suited to editable flow diagrams, not a 500-node force web.
- **Cost:** about 94 KB gz plus graphology (not measured). The force layout uses client CPU. No license conflict for GPL or commercial use.

- React Flow docs on performance and Pro features.

### Tentative recommendation
- **Recommend:** Leaflet 1.9.4 (BSD-2, about 42 KB gz), used directly from a small custom React 18 wrapper (useRef/useEffect), with L.CRS.Simple and pins stored as image-pixel `[y, x]`. Do **not** use react-leaflet: it is Hippocratic-2.1 licensed, and v5 requires React 19. Small maps use ImageOverlay. Large maps get a DeepZoom pyramid from libvips `dzsave` on the server when the image is uploaded, loaded with leaflet-deepzoom (check that plugin's license and maintenance).
- **Runner-up:** OpenLayers 10.11.0 (BSD-2). It has a first-party Zoomify source and pixel projection, so it needs no third-party plugin. Its bundle size was not measured this run, and it is believed to be larger.
- **Cost:** about 42 KB gz plus a plugin, client-side. Tiling costs CPU once per upload on the server (libvips; speed not measured this run) and about 1.33x the image's storage (unverified).
