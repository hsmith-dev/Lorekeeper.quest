# Tech-currency review: Lorekeeper architecture spine

## Verdict

**Pass with fixes.** Most stack picks are current, exist and carry the licences the spine expects. Six claims need changing before epics build on them:

1. **Blocker:** `sse-starlette 3.6.0` cannot be installed next to the existing `fastapi==0.115.0`. It needs `starlette>=0.49.1`, and FastAPI 0.115.0 pins `starlette<0.39`.
2. **Blocker:** pgvector on Homebrew cannot be paired with `postgresql@16`. The Homebrew `pgvector` formula builds only against `postgresql@17` and `postgresql@18`, and the dev Mac currently has only `postgresql@16 16.15` installed, with no pgvector.
3. **Wrong:** `rq 2.9.1` is not the newest 2.x release. 2.10.0, 2.11.0 and 2.12.0 (2026-08-30) came after it. The memlog's reason for the pin ("3.0.0 is 3 days old") still holds, but the pin should be 2.12.0.
4. **Wrong:** AD-6 requires every sidecar to serve `/healthz` and `/v1/status`. The upstream Kokoro-FastAPI image serves `/health` and has no `/v1/status`.
5. **Wrong:** the AD-7 tts row says "Kokoro quantized, lazy, 512m". The CPU image actually runs PyTorch (`torch==2.8.0`), not a quantized ONNX model, and it loads and warms the model at startup.
6. **Wrong:** `license-checker` (npm) has had no release since 2019-01-10. The maintained fork is `license-checker-rseidelsohn`.

Statuses: **verified** (reality matches the spine), **wrong** (reality contradicts it), **unverifiable** (could not be confirmed with available sources), **risk** (true but with a consequence the spine does not address).

## Suggested spine edits (summary, for the author)

1. Stack: `rq` → 2.12.0. Remove the `sse-starlette` row, or make it conditional on a FastAPI upgrade.
2. AD-6: tts health is `/health`, there is no `/v1/status`, and `voices` returns objects.
3. AD-7 tts row: PyTorch fp32, eager. The RAM figure is unverified. Make lazy mean "container started on demand".
4. AD-8: drop or probe-gate the native `/api/chat` path for provider `kobold`.
5. AD-21: pgvector on Homebrew pg16 must be built from source, or local dev moves to pg17.
6. AD-22: use `license-checker-rseidelsohn`. Allowlist LGPL system libraries (libvips, Pango, GLib). Add an image-level (dpkg or syft) scan. Install libvips from apt, not `pyvips[binary]`.
7. ml: record that sentence-transformers ONNX still installs and imports torch. Consider using onnxruntime + tokenizers directly. Choose quantized ONNX files per CPU ISA. Map NLI labels through `id2label`.
8. stt: convert PCM16 to float32 before calling `transcribe`. Use the bundled Silero VAD.
9. AD-14 / map convention: tile layout (DeepZoom or Google) must match the route shape and the Leaflet tile URL function.
10. Pin `ollama/ollama` and `pgvector/pgvector` by exact tag.
